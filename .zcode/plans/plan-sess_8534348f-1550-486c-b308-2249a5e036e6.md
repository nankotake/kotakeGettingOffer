## 目标
在仓库根目录新建 `jd_qa/` 文件夹,集中管理测开/QA 岗位的 JD,并把每条 JD 转成与仓库已有内容(`learning/python/`、`interview/`、`cpp/`)联动的可执行备战清单。扁平结构 + 规范文件名。

## 最终结构
```
kotakeGettingOffer/
├── cpp/ interview/ learning/  (不变)
└── jd_qa/                       ← 新增
    ├── README.md                ← 文件夹说明 + 命名规范 + 用法
    └── _TEMPLATE.md             ← 完整备战型 JD 记录模板(复制即用)
```

## 文件 1:`jd_qa/README.md`
内容包含:
1. **文件夹用途**:存放测开/QA 岗位 JD,并转成备战清单
2. **命名规范**:`{公司}_{岗位简称}_{YYYYMMDD}.md`,给出 `腾讯_测开_20260730.md` 等示例
3. **用法**:复制 `_TEMPLATE.md` → 改名为上述格式 → 填写 → 投递后在文件顶部更新「状态」
4. **状态约定**:待投递 / 已投递 / 笔试 / 一面·二面·HR面 / Offer / 已挂
5. **与仓库联动说明**:
   - 技能拆解对照 `learning/python/` 的学习计划(指向 `Python学习计划.md`)
   - 关联真题指向 `interview/`(如已有 `腾讯测开1面.cpp` ~ `腾讯测开3面.cpp`)
   - 弱项题型指向 `cpp/` 对应题解
6. **目录索引表**(可选,留一个空表格便于后续登记)

## 文件 2:`jd_qa/_TEMPLATE.md`(完整备战型)
字段结构:
- **基础信息** 公司 / 岗位 / 投递日期 / 渠道(内推·官网·BOSS等) / 状态 / JD 链接
- **JD 原文** 职位职责 + 任职要求(原样粘贴两块)
- **重点技能拆解** 把 JD 技术点逐条列出,每条标注「✅已掌握 / 🟡学习中 / ❌未学」,并填 `learning/` 或 `cpp/` 对应路径
- **关联已有真题/刷题** 链接到 `interview/` 或 `cpp/` 中相关文件
- **备战 checklist** 针对 JD 弱项的具体行动项(待办列表 `- [ ]`)
- **面试记录区** 预留(笔试/各轮面试心得 + 结果)

## 不做的事
- 不创建任何示例 JD(留空模板即可,等你实际投递再复制)
- 不动现有任何文件
- 不配置构建/依赖(纯 Markdown)

## 执行步骤
1. 新建文件夹 `jd_qa/`
2. 写入 `jd_qa/README.md`
3. 写入 `jd_qa/_TEMPLATE.md`
