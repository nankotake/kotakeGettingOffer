## 五、系统设计(Day 6)— 测开视角

- [ ] `[必会]` **设计一个 AI 测试 Agent 架构**(= 岗位本身,最高频)
  - _框架:需求澄清→模块拆分(探查/规划/执行/判定)→数据流→工具集→异常处理→监控_
- [ ] `[重点]` **设计 Coding Agent 流式输出的测试方案**
  - _框架:测什么(token 完整性/时延/中断)→怎么测(抓包/CDP/断言)→监控_
- [ ] `[重点]` **设计一个接口自动化测试平台**(经典题)
  - _框架:用例管理/执行引擎/数据驱动/报告/CI 集成_

### 设计题通用框架
1. 先花 2 分钟澄清需求、定边界(切忌上来就写)
2. 拆模块 / 画数据流
3. 定测试点 / 监控 / 告警
4. 讲权衡取舍(为什么这么选、备选方案)
5. 主动嵌入你的真实经验("这块我用 managed agent 做过...")
