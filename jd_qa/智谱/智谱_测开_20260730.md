## JD 原文

### 职位职责
1. 负责 Coding Agent 客户端(桌面 Electron + Web 远程控制 + 手机端)的质量保障,系统性地识别与攻克质量风险,持续提升产品稳定性
2. 以 AI 工具深度参与测试全流程:从用例设计、缺陷定位、回归验证到质量分析,将 AI 能力嵌入日常测试工作流,显著放大个人与团队的测试效率
3. 搭建并持续演进 AI 测试 Agent:独立设计和落地能够自主探查界面、复现用户路径、构造对话任务、分析流式与状态问题的测试 Agent 体系,覆盖多端场景
4. 构建面向 AI 编程 Agent 产品的端到端自动化测试体系:覆盖流式 token 输出、思考过程、工具调用追踪、diff/补丁、权限请求、长任务中断/恢复/重连等核心交互链路
5. 针对客户端多端/多形态做专项测试:macOS/Windows/Linux 桌面端、Web 远程控制、手机 Web 端,保障跨端交互与状态同步一致性
6. 负责质量专项建设(性能、稳定性、流式与实时链路、远程 workspace 等),设计并实现质量工具/平台,在团队内推广落地
7. 优化产研流程与质量标准,推动过程质量持续改进,提升项目迭代效率

### 任职要求
1. 本科及以上,计算机/软件工程或相关专业,**3-5 年互联网公司测试开发经验**
2. **必须有深度使用 AI 工具参与测试工作的实践经验**,熟悉主流 AI Coding/Agent 工具(如 ZCode、Claude Code 等),能将其作为日常测试生产力底座
3. **具备自主搭建完善 AI 测试 Agent 的能力**:理解 Agent 任务编排、工具调用、上下文管理,能从 0 到 1 设计并实现面向客户端测试场景的自动化 Agent
4. 扎实的服务端测试经验,熟悉 **SSE、WebSocket、WebRTC** 等实时通信协议,能对流式响应、长连接保活、断线重连进行有效测试与问题定位
5. 有客户端测试经验,熟悉 **Electron / Web / 移动端 Web** 的测试方法与自动化框架
6. 有服务端接口测试能力,熟悉接口协议、契约测试与 **mock / 录放**
7. 有专项测试经验(性能、稳定性、兼容性等),有 **0-1 测试工具/平台搭建经验**者优先
8. 较强的发现与解决问题能力:能基于**日志、CDP、运行时链路**等定位根因,而非简单兜底
9. 自驱力强,沟通与组织协调能力优秀,抗压能力强,责任心强

### 加分项
- 有 AI Agent / AI App / LLM 应用测试经验,熟悉流式对话与 Agent 交互范式的质量保障
- 有多端协同测试经验,理解跨端状态同步、远程控制、实时链路的测试难点
- 有远程 workspace(SSH / WSL / Docker)相关链路测试经验
- 主导过 AI 测试 Agent 或测试智能化平台的建设与落地
- 有开源项目、技术博客,或质量工程相关分享
