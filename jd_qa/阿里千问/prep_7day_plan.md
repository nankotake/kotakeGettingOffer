# 阿里千问测开 · 技术面 7 天备战计划

> **背景**:阿里千问测开岗(服务端与策略研发方向)。备战窗口:约 1 周(投递前 + 面试前)。
> **核心策略(与智谱版的关键差异)**:千问岗**无致命短板**(硬性要求全命中),所以不是「补短板」模式,而是「**夯实基本盘 + 把两个加分项讲出彩**」模式。
>   - 智谱版是「Agent 命门 + 客户端短板」,重心在补客户端/流式;
>   - 千问版是「**中大型系统测试 + 策略测试 + 线上监控/Trace + 测试平台**」为主轴,「AI Agent / 搜推转广告」为放大器。
>   - **取舍纪律**:基本盘(S 级)没吃透,绝不投入加分项深处。宁可加分项「聊得明白」,不要基本盘「半生不熟」。

## 2. 阿里面试的预期特点 & 应对

> 阿里测开技术面通常 2-3 轮,风格偏「**项目深挖 + 系统设计 + 基础扎实度**」,且重视「贴近业务、方案整合、落地能力」。与智谱(技术深度公司、抠原理)不同,阿里更看重「**你能不能把事做成、做成体系**」。

### 可能的面 1:项目 & 基础面(直接 leader / 资深测开)
- **重心**:简历项目往深里挖(风控/搜推/AI 工具),关注「你具体做了什么、结果数据、复盘」
- **考点**:测试策略设计、策略系统测试、中间件链路、自动化框架、线上问题 Trace
- **你的策略**:主动把话题引向搜推策略系统 + 线上监控(基本盘最强项),每个项目用 STAR 讲透,主动给数据和复盘
- **防御点**:广告经验坦诚「无直接经验,但搜推策略测试同源可迁移,正在补广告业务知识」,不硬撑

### 可能的面 2/3:系统设计 & 架构面(架构 / 交叉面)
- **重心**:技术广度 + 一个开放系统设计题 + 软素质 / 方案整合能力
- **考点**:测开八股广度、一个设计题(大概率是「测试平台」或「监控/Trace 体系」)、AI Agent/广告加分
- **你的策略**:广度题快答不拖;设计题用通用框架结构化输出;主动结合美团 0-1 经验(告警系统/数据测试模板/风控闭环/AI 平台)讲体系化能力
- **加分动作**:设计题里主动提「这块我用 managed agent / 平台视角做过」,把项目自然嵌入答案;主动聊「搜推→广告迁移」体现业务理解

### 关键纪律(通用)
- **不会就说「这块我了解不深,但我的理解是 X,不确定对不对」** —— 比硬编强百倍,阿里同样反感不懂装懂
- **每个答案尽量落回你的真实项目** —— "我在美团做搜推/风控/AI 工具时..." 是你最可信的弹药
- **数据要讲口径**:10→2 是什么周期、什么口径;90% 准确率怎么算的——数字不清会被追问到底
- **广告短板统一口径**:无直接经验 + 搜推策略同源可迁移 + 正在补广告业务知识(可讲 eCPM/GSP 等概念证明你在学),不要假装很熟

## 4. 每日节奏建议(可调)

```
上午(精力好): S 级主线块   → 项目深挖 / 系统测试 / 监控 Trace
下午:          A 级补强块   → 平台/Agent / 广告补课
```
