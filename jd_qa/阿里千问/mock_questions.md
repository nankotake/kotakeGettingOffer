# 高频问题清单(阿里千问方向,贯穿 7 天,持续补充)

> **用法**:这是 7 天里所有学习笔记的问题汇总索引。每天学完,把「自己卡壳/答不顺」的问题补到这里,考前集中过一遍。
> **标记规则**:`[必会]` JD 硬性或高频 · `[重点]` 岗位相关高频 · `[了解]` 广度加分。
> **自测方式**:对着问题先口头答一遍,卡壳的标 ❌,考前重点过 ❌。
> **与智谱版差异**:本版**主轴是「中大型系统测试 + 策略测试 + 线上监控/Trace + 测试平台」**(JD 核心),AI Agent / 流式降为加分项(精简),**新增「广告/策略测试」「A/B 实验」专题**。

### 设计题通用框架
1. 先花 2 分钟澄清需求、定边界(切忌上来就写)

3. 定测试点 / 监控 / 告警
4. 讲权衡取舍(为什么这么选、备选方案)
5. 主动嵌入真实经验("这块我在美团用 managed agent 做过...")
